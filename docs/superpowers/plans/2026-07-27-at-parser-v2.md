# AT Parser V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the AT parser as an elegant local-first security console, account dashboard, permissions view, and advanced inspector while publishing a single offline HTML file.

**Architecture:** Source code is split into pure core modules and a DOM controller under `src/`. Vite and `vite-plugin-singlefile` bundle JavaScript, CSS, and Lucide icons into `dist/index.html`; a release script copies the verified artifact to the repository-root `index.html`. Core tests import source modules directly, while build/security tests inspect the generated artifact and Playwright verifies rendered behavior.

**Tech Stack:** Vanilla JavaScript ES modules, semantic HTML, CSS custom properties, Vite 8.1.5, vite-plugin-singlefile 2.3.3, Lucide 1.27.0, Node 24 built-in test runner, Microsoft Edge Playwright fallback.

Export the following concrete behavior:

```js
export const NAMESPACE_LABELS = new Map([
  ["https://api.openai.com/auth", "OpenAI Auth"],
  ["https://api.openai.com/profile", "OpenAI Profile"],
]);

export function describeClaim(key) {
  return CLAIM_DEFINITIONS[key] ?? {
    label: key,
    description: "尚未提供语义解释，已保留原始声明。",
    category: "other",
    known: false,
  };
}

export function buildClaimEntries(header, payload) {
  const output = [];
  const visit = (value, context) => {
    if (value !== null && typeof value === "object" && !Array.isArray(value)) {
      for (const [childKey, childValue] of Object.entries(value)) {
        const isNamespace = context.source === "payload" && NAMESPACE_LABELS.has(childKey);
        visit(childValue, {
          source: context.source,
          namespace: isNamespace ? NAMESPACE_LABELS.get(childKey) : context.namespace,
          path: [...context.path, childKey],
          key: childKey,
        });
      }
      return;
    }
    const definition = describeClaim(context.key);
    const sensitive = isSensitiveKey(context.key);
    output.push({
      source: context.source,
      namespace: context.namespace,
      key: context.key,
      path: context.path.join("."),
      label: definition.label,
      description: definition.description,
      category: definition.category,
      sensitive,
      known: definition.known !== false,
      value,
      searchPreview: sensitive ? "" : formatSearchPreview(value),
    });
  };
  visit(header, { source: "header", namespace: "JWT Header", path: ["header"], key: "header" });
  visit(payload, { source: "payload", namespace: "JWT Payload", path: ["payload"], key: "payload" });
  return output;
}

export function selectPreferredClaim(entries, key) {
  return entries.find(entry => entry.key === key && entry.namespace === "OpenAI Auth")
    ?? entries.find(entry => entry.key === key && entry.source === "payload")
    ?? null;
}

export function buildAccountSummary(entries) {
  return {
    plan: selectPreferredClaim(entries, "chatgpt_plan_type"),
    residency: selectPreferredClaim(entries, "chatgpt_compute_residency"),
    authentication: entries.filter(entry => ["amr", "email_verified", "is_signup", "pwd_auth_time", "sl"].includes(entry.key)),
  };
}
```

`CLAIM_DEFINITIONS`, `isSensitiveKey`, and `formatSearchPreview` are module-local data/imports defined in the same step; `formatSearchPreview` returns a compact JSON string for public values and an empty string for `undefined`.

Each entry must have:

```js
{
  source: "payload",
  namespace: "OpenAI Auth",
  key: "chatgpt_plan_type",
  path: "payload.https://api.openai.com/auth.chatgpt_plan_type",
  label: "JWT 声明的套餐",
  description: "Token 签发时记录的 ChatGPT 套餐，可能不是当前服务器状态。",
  category: "account",
  sensitive: false,
  known: true,
  value: "plus"
}
```
